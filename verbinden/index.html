Handy verbinden

Verbindet ein Gerät mit deiner Sense Engine, damit die Figuren mit ihrer eigenen Stimme sprechen. Ohne Kopieren.

  1. «QR-Code zeigen» tippen.
  2. Mit der iPhone-Kamera auf den Code halten und den gelben Link antippen.
  3. Das iPhone öffnet diese Seite in Safari und ist verbunden.

Der Code enthält dein Passwort: kein Foto, kein Bildschirmfoto. Er verschwindet nach 2 Minuten.

Verbindung gespeichert. Ich teste …

Apps auf dem Home-Bildschirm (mit Icon) haben einen eigenen Speicher. Für sie: Code kopieren, die App öffnen, auf die Figur unten rechts tippen, «Verbindung einsetzen».

Jetzt die Apps in Safari öffnen, z. B. Kiki, Mondschein, Jackie.
