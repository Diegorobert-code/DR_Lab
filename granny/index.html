Granny

Ich bin da. Drück den goldenen Knopf und rede mit mir.

Für Angehörige

Hier richten Sie Granny für Ihren Elternteil ein. Alles bleibt nur auf diesem Gerät. Nichts wird gesendet, ausser Sie tragen unten eine Server-Adresse ein.

Die 4 Knöpfe

Name, Telefonnummer mit Ländervorwahl und ein Foto. Ein Druck auf den Knopf ruft direkt an.

Hilfe-Knopf

Im Notfall immer 144 (Schweiz) oder 112 (Spanien/EU). Granny ersetzt keinen Notruf.

Handy klemmt / Passwort

Granny fragt nie nach Passwörtern. Passwörter verwalten die Angehörigen.

Heute

Später: Server

Wenn der Server läuft, kann Granny frei antworten. Leer lassen = Granny antwortet einfach selbst, ohne Internet.

Granny ist keine Ärztin und stellt keine Diagnose. Fragen zu Gedächtnis und Demenz: Hausarzt oder Alzheimer-Telefon Schweiz 058 058 80 00 (Mo–Fr). Entwurf DR Lab, nicht veröffentlicht.
