Hasis Werkbank

Hasi krempelt die Ärmel hoch und legt fünf Vorlagen auf die Werkbank. Wähle eine Vorlage, gib Name, Farbe und Einträge ein. Dein kleines Programm entsteht daneben, ohne Programmieren.

«Mitnehmen» speichert eine HTML-Datei auf deinem Gerät. Sie läuft ohne Internet und ohne Konto. Aufschalten mit eigener Adresse folgt nach Go.

Auf Bestellung: Hasi baut es für dich

Nichts Passendes gefunden? Beschreib dein Werkzeug. Letti trägt den Wunsch als goldenen Brief zu Hasi. Im Entwurf bleibt der Brief auf diesem Gerät, es wird nichts gesendet.

Hasi liest Code

Hasi spricht nicht, aber er versteht jede Codiersprache. Gib ihm ein Stück Code. Er antwortet mit Gesten: Daumen hoch heisst «läuft», Kopfschütteln heisst «Fehler», der Schraubenschlüssel heisst «ich repariere».

Regal der Erfinder

Andere Leute können ihre Programme bei Hasi ausstellen. Hasi prüft jeden Würfel mit seiner goldenen Waage. Vorerst nur Gratis-Programme, nur mit freier Lizenz (MIT, Apache, BSD). Verkauft wird nichts von Dritten.

Was Hasi sich merkt

Kleingedrucktes
  • Grundprogramme im Grossen Regal sind gratis. Hasi verkauft nur Einrichten, Aufschalten und Hilfe, nie den fremden Code.
  • Bei jedem fremden Werkzeug stehen Lizenz und Name der Erfinder. Nur MIT, Apache 2.0 oder BSD. Ohne Lizenz nie.
  • Fremde Programme werden erst mit der GmbH und nach Prüfung durch eine Fachperson verkauft. Bis dahin nur gratis mit Link.
  • Aufnahme halbautomatisch: Claude prüft Lizenz und Sicherheit, Diego gibt pro Programm ein Go. Nichts geht von selbst live.
  • Bezahlt wird nur im Web, nie in einer iPhone-App.
  • Alles auf dieser Seite bleibt in deinem Browser. Ohne Server geht nichts weg.
  • Vorgemerkt, noch nicht gebaut: Gäste im KI-Verse können bewusst Geteiltes in Hasis Laden stellen.
